# Day 25 · Type Atlas

**Is this a map?** is the 30DayMapChallenge theme for November 25, 2026. [2026 challenge themes](https://30daymapchallenge.com/#2026-themes)

Zoom from countries woven out of their own names to streets and individual buildings drawn in punctuation. Waves travel diagonally across water, and river names flow between their banks. Press **P** to pause or resume the animation. [Explore Type Atlas](https://maps.tileflow.dev/type-atlas/)

## Run locally

In this directory, run the following with Node.js 24 and pnpm.

```sh
pnpm install
pnpm dev
```

Country silhouettes at world scale come from [Natural Earth](https://www.naturalearthdata.com/). Map data, including the water geometry used to place the lettering in the New York rivers, © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), under the [ODbL](https://opendatacommons.org/licenses/odbl/1-0/).
