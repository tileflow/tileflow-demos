# Day 19 · SNIFF!

**Senses: Smell** asks how to map what your nose can detect. [2026 challenge themes](https://30daymapchallenge.com/#2026-themes)

Follow a scent trail through real streets to find your next bite before time runs out. [Play SNIFF!](https://maps.tileflow.dev/sniff/)

## Run locally

In this directory, run the following with Node.js 24 and pnpm.

```sh
pnpm install
pnpm dev
```
