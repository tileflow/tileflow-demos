# Day 17 · Sun on the street

**Light & dark** asks what a map can show using light and shadow. [2026 challenge themes](https://30daymapchallenge.com/#2026-themes)

Pick a sidewalk and a time of day to see when it gets direct sunlight. [Explore the map](https://maps.tileflow.dev/sun-on-the-street/)

## Run locally

In this directory, run the following with Node.js 24 and pnpm.

```sh
pnpm install
pnpm dev
```
